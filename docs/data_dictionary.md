# Data dictionary

Generated by `src/data_dictionary.py` from `data/hr.duckdb`.

**Three separate subject areas.** IBM = fictional IBM HR dataset. UCI = real absence records of a different company (Brazilian courier). SIMULATED = generated recruiting pipeline. The UCI tables never join to IBM or SIMULATED tables.

Power BI copies of these tables are in `powerbi/model/` (SIMULATED tables have `_SIMULATED` in the file name; `dim_employee` there drops the department columns, which come from `dim_job_role`; two small helper dimensions `dim_absence_month` and `dim_weekday` are added).

## dim_department

Source: **Shared (IBM departments)**. One row per IBM department. Used by IBM and SIMULATED tables. Rows: 3.
